# PRG1: Iteration (PRIM activities)

Day 3, session 2. Four activities, each in its own folder, code and tasks together.

## PRIM

| Step | What you do |
|---|---|
| **Predict** | Say what the code will do **before** you run it. Write it down. |
| **Run** | Run it. Compare against your prediction. |
| **Investigate** | Work out *why* it behaves that way. |
| **Modify** | Change something specific, predicting the effect before each change. |

Work in pairs, and swap who drives at each new activity.

## The activities

| Folder | Focus |
|---|---|
| `activity-1-counting/` | How many times does this run? |
| `activity-2-accumulating/` | Building up a value across passes |
| `activity-3-while-and-stopping/` | Every route out of a loop |
| `activity-4-broken-loops/` | Three faults in code that runs |

Reach activity 4 if you can. 

## If you finish

| Folder | Focus |
|---|---|
| `stretch-1-nested-loops/` | A loop inside a loop, and how many times things run |
| `stretch-2-enumerate-and-zip/` | Two tools you will read before you write |

Activity 3 also carries an optional **Make** at the end. None of this is
expected. Reach it only once the four core activities are genuinely done, which
means you can explain them, not just that you ran them.

## Running a file

```
python activity-1-counting/counting.py
```

If `python` is not recognised, use `python3` instead.
